桌面倒计时 v0.3.1
==================

运行环境
--------
Windows 10 / Windows 11，系统需安装 .NET Framework 4.8（当前电脑已经具备）。

开始使用
--------
1. 双击 DesktopCountdown.exe。
2. 首次启动会自动打开设置页。
3. 输入目标时间，格式为 yyyy-MM-dd HH:mm:ss。
4. 选择艺术风格后保存。

操作说明
--------
- 未锁定时：按住倒计时窗口左键拖动。
- 拖到屏幕工作区边缘附近时，以可见卡片边缘自动贴边；透明阴影区不会留下视觉空隙。
- 双击倒计时：打开设置。
- 右键倒计时或托盘图标：切换主题、锁定、置顶、校时或退出。
- 锁定并穿透后：窗口不会拦截桌面鼠标；请从系统托盘解除锁定。
- 桌面层模式已移除；可按需使用普通窗口或“始终置顶”。
- 设置页可分别调整倒计时主体和“现代留白”右上角的日期时间格式。
- 防烧屏微位移默认关闭，可按需选择六种移动方式并调整间隔、幅度。
- 如需登录后启动，可选普通启动项或任务计划程序中的登录任务。

默认视觉
--------
中文标题：MiSans Regular
数字：Bahnschrift SemiBold
默认主题：极简玻璃

内置主题
--------
极简玻璃、现代留白、编辑部海报、暮色星轨、东方墨韵、深海夜航、青瓷晨雾、霓虹夜行、琥珀胶片、蓝图刻度。

数据与网络
----------
设置保存在：%LOCALAPPDATA%\DesktopCountdown\settings.json
程序没有遥测和账户功能。只有自动校时时会访问设置中的 NTP 服务器，默认是 time.windows.com。

卸载
----
先从托盘菜单退出，再删除程序文件即可。如需清除设置，可自行删除上述 DesktopCountdown 设置目录。
